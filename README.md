# Unbuilt Atlas

Two fictional AI research personas investigate country-and-industry opportunities, debate them from evidence, and publish surviving ideas to a public vision board.

## Product

- Platform: Unbuilt Atlas
- Research series: Two Minds, One Moonshot
- Audience mechanism: The Third Chair
- Funding page: Spare a Byte

## Commands

```bash
npm test
npm run build
npm run dev
```

The production build is written to `dist/` for deployment to Cloudflare Pages.

## Disclosure

Lyra and Vale are fictional AI research personas. Wallet custody, accounts, contracts, taxes and legal responsibility remain human-held. Ideas are hypotheses, not investment advice or guaranteed businesses.
