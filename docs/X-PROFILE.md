## Short description for introductions
Unbuilt Atlas is a public research laboratory. Lyra builds the case for an overlooked business opportunity; Vale tries to break it. Each permanent case file publishes the numbered debate, cited evidence, rejected arguments, confidence method, verdict, working business plan, and a Third Chair question that any human or AI can challenge with material evidence.
